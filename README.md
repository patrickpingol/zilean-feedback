[Zilean](https://zilean.dev), the self-hosted scheduled job runner.

## Report a bug

[Open a bug report](https://github.com/patrickpingol/zilean-feedback/issues/new?template=bug_report.yml)

Please include your Zilean version (shown in the admin UI sidebar, or from
`GET /api/meta`), steps to reproduce, and any relevant logs.
**Remove secrets, tokens and connection strings before you post.**

## Request a feature

[Open a feature request](https://github.com/patrickpingol/zilean-feedback/issues/new?template=feature_request.yml)

Describe the problem you're trying to solve, not only the solution you
have in mind. It helps to know what you're doing today as a workaround.

## Before you open an issue

- Check the [documentation](https://zilean.dev). The answer may already
  be there.
- Search [existing issues](https://github.com/patrickpingol/zilean-feedback/issues?q=is%3Aissue)
  so you don't open a duplicate. If someone has already asked, add a 👍
  reaction instead of a new comment.

## What happens next

New issues are labelled `triage` until they've been reviewed. Fixes and
new features are announced in the
[changelog](https://zilean.dev/reference/changelog/).

## Security issues

Please don't report security vulnerabilities in a public issue.
Email [support@zilean.dev](mailto:support@zilean.dev) instead.
